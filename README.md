# Bug Portfolio

這個專案整理我在客服問題排查、POS 系統問題分析、線上點餐串接異常與報表/列印問題中處理過的案例。

每個案例都會把原始店家、訂單、帳號、單號、網址、時間等可識別資訊去識別化，只保留問題情境、查詢結果與處理判定。

## 內容格式

每個案例大致包含：

- 客服反映內容
- 查詢結果
- 處理判定

處理判定通常分為：

- 操作/設定問題，請客服向店家說明
- 系統問題，已上 Redmine 請 RD 修正

## 分類

```text
cases/
  operation/  操作、設定、店家流程理解造成的問題
  printing/   出單、廚房單、標籤、列印紀錄相關問題
  security/   登入驗證、權限控管、越權操作相關問題
  system/     系統邏輯、同步時序、報表計算、後台功能錯誤
```

## 目的

這個 repo 主要用來展示：

- 將客服描述轉成可查證問題
- 依 log、DB、操作流程與版本差異定位原因
- 區分操作問題與系統問題
- 將排查結論整理成可交付給客服或 RD 的紀錄

所有內容皆為去識別化後的案例整理，未包含原始客戶資料或軟體內部查詢語法。
如出現SQL語法均為我在查詢問題過程中撰寫，部分因具有可重複使用性，有提供給公司，如刪除關鍵key後不具可辨識性才會上傳。
