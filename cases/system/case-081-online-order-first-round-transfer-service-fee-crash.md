# Case 081 - 線上訂單移菜或退廚後切換服務費閃退

## 自主測試內容

POS 版次：v4.X.X

結帳方式：後結

線上點餐平台版本：平台版本二

第一次線上點餐進單後關閉服務費，再收到第二次加點，移走或退廚第一次點餐品項後，切換原桌服務費會造成閃退。

## 查詢結果

重現步驟：

1. 開桌列印掃碼點餐單，送入第一次線上點餐的商品 A、B。
2. 在 POS軟體關閉服務費並掛單。
3. 線上再加點商品 C。
4. 將商品 A、B 移至另一桌，或對第一次品項操作退廚。
5. 開啟原桌服務費，部分測試在開啟時閃退，部分需再關閉才會閃退。

對照測試：若移菜或退廚的是第二次加點品項，沒有觀察到相同問題。

## 處理判定

系統問題，已回報 Issue 管理系統。需檢查不同加點批次異動後的服務費計算與訂單狀態。
