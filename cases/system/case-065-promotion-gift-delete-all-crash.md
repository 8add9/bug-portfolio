# Case 065 - 促銷贈品畫面操作全部刪除造成閃退

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：[線上點餐平台]

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，訂單套用滿量贈促銷後，進入「點我選贈品」畫面操作全部刪除會造成 POS 閃退。不論先前是否已選擇贈品，都可以重現。

## 查詢結果

測試流程：

- [DATE] [TIME]：點選桌號並開始點餐。
- [DATE] [TIME]：點選「點我選贈品」。
- 選擇一項贈品並確認。
- 再次進入「點我選贈品」。
- [DATE] [TIME]：點選全部刪除，POS 發生閃退。

交叉測試：

- 尚未選擇任何贈品時，直接點選全部刪除也會閃退。

判斷贈品全部刪除流程未正確處理空集合、既有選取狀態或促銷贈品關聯資料，例外未被攔截而造成閃退。

## 處理判定

系統問題，已上 Issue [ID]，請開發端修正促銷贈品全部刪除流程，並加入空資料與既有贈品狀態的防呆處理。
