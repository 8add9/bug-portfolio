# Case 060 - 線上訂單特殊符號備註於桌況畫面顯示編碼文字

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：[線上點餐平台]

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，在線上點餐平台的整單備註輸入小於、大於、雙引號與 `&` 等特殊符號後，訂單進入 POS 時，桌況畫面的整單備註會顯示為 encode 後的文字，而不是使用者實際輸入的符號。

前結內用以及前、後結外帶訂單均可重現。

## 查詢結果

測試流程：

- 在線上點餐平台整單備註輸入特殊符號。
- [DATE] [TIME]：前結內用訂單進入 POS，桌況畫面的整單備註呈現編碼文字。
- [DATE] [TIME]：外帶訂單進入 POS，桌況畫面的整單備註同樣呈現編碼文字。

判斷整單備註在訂單寫入、同步或桌況畫面顯示流程中的 encode/decode 處理不一致。此案影響桌況畫面，與單據列印備註編碼問題屬於不同呈現介面。

## 處理判定

系統問題，已上 Issue [ID]，請開發端修正桌況畫面整單備註的解碼與安全顯示邏輯，並確認不同結帳方式與銷售方式的處理一致。
