# Case 094 - 單項操作期間鍵盤切換區域後金額計算異常

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

結帳方式：前結

門店反映結帳時畫面反白、沒有動作，曾多次自行從 Windows 重新啟動；本次重啟後黑屏，客服引導斷電重接才成功開機，希望確認是否為既有問題。

## 查詢結果

查得異常操作順序：

1. 點選商品並開啟單項操作。
2. 透過鍵盤 Tab 與 Space 切換左側掛單顯示區域；該操作階段正常不應允許切換。
3. 調整商品數量。
4. 事件紀錄顯示訂單金額計算流程遇到空值。

推測調整數量觸發金額計算；已觀察到相關異常也出現在提單與結帳。開發端回覆已調整。


## 處理判定

系統問題，開發端已回覆調整單項操作期間的區域切換與金額計算異常。
