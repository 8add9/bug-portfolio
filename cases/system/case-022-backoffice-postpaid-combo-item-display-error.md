# Case 022 - 後結帳訂單查詢套餐子項顯示錯誤

## 客服反映內容

測試日期：[DATE]  
POS 版次：v4.X.X  
結帳方式：後結  
線上點餐平台版本：[線上點餐平台]  
線上點餐平台帳號/密碼/檢碼：[SECRET]

問題：

在線上點餐平台加點時，若先加點一般商品，再加點套餐，後台訂單管理的後結帳訂單查詢中，訂購餐點不會顯示套餐子項。

## 查詢結果

### 第一次測試

操作流程：

- [DATE] [TIME]：選擇桌號並列印掃碼點餐單。
- [DATE] [TIME]：先加點一般商品。
- [DATE] [TIME]：再加點套餐。
- [DATE] [TIME]：送出本次訂單。

後台查詢結果：

- 後台路徑：訂單管理 > 後結帳訂單查詢 > 管理 > 訂購餐點。
- 套餐未帶出套餐子項。
- 套餐金額呈現 780 元。
- 服務費呈現 78 元。
- 總金額呈現 858 元。

正確應呈現：

- 套餐基本價 x1：780 元。
- 套餐子項 A x1：0 元。
- 套餐子項 B x1：0 元。
- 套餐子項 C x1：25 元。
- 套餐子項 D x1：0 元。
- 套餐金額：805 元。
- 服務費：81 元。
- 總金額：886 元。

### 第二次測試

操作流程：

- [DATE] [TIME]：先加點套餐。
- [DATE] [TIME]：再加點一般商品。
- [DATE] [TIME]：送出本次訂單。

後台查詢結果：

- 第二次點餐可正確帶出套餐子項與套餐金額。
- 服務費呈現 159 元，正確應為 161 元。
- 總金額呈現 1744 元，正確應為 1771 元。

## 處理判定

系統問題，已上 Issue 管理系統，請開發端 確認後結帳訂單查詢在不同加點順序下的套餐子項顯示與金額計算邏輯。
