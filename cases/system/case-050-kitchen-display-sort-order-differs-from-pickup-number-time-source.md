# Case 050 - 廚房顯示系統排序與取餐號順序不一致

## 客服反映內容

項次：[ID]

門市：[門市/公司]

POS 版次：v3.X.X

結帳方式：前結

日期：[DATE]

取餐號：[ID]

客服反映門市使用 POS01 點選外帶餐點後，訂單進到 廚房顯示系統 時，沒有依照取餐號順序排序。

## 查詢結果

查詢後確認，取餐號與 廚房顯示系統排序使用的時間來源不同。

取餐號產生邏輯：
- POS 開單時會取得 標準時間。
- POS 會依該 標準時間查詢該時間點以前的最後一筆訂單取餐號。
- 再用最後一筆取餐號遞增產生新取餐號。

例如：
- POS 取得標準時間為 [TIME]。
- 系統查詢 [TIME] 以前最後一筆訂單的取餐號為 30。
- 新訂單取餐號會產生為 31。

廚房顯示系統排序邏輯：
- 廚房顯示系統依訂單時間排序。
- 該訂單時間來源為 POS 本機時間。

現場兩台 POS 的時間差：

- POS01 本機時間比 標準時間快約 1 分 34 秒。
- POS02 本機時間比 標準時間快約 11 秒。
- POS01 與 POS02 兩台本機時間相差約 82 秒。

因此若 POS01 與 POS02 操作開單時間差低於 82 秒，且由 POS01 先開單，就可能發生：

- 取餐號依 標準時間正常遞增。
- 廚房顯示系統依 POS 本機時間排序。
- 因 POS01 本機時間較快，廚房顯示系統排序結果與取餐號順序不同。

## 處理判定

系統問題。

此案原因為取餐號產生與 廚房顯示系統排序採用不同時間來源，當多台 POS 本機時間存在差異時，會造成取餐號順序與 廚房顯示系統顯示順序不一致。
