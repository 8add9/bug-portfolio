# Case 016 - 交班帳交易總筆數與總桌數不符

## 客服反映內容

項次：[ID]  
店名：[門市/公司]  
POS 版次：v3.X.X  
線上點餐平台版本：[線上點餐平台]  
線上點餐平台帳號/密碼/檢碼：[SECRET]  
結帳方式：後結

日期：[DATE]  
交班時間：[DATE] [TIME] ~ [DATE] [TIME]

客服回報交班帳條的交易總筆數為 74 筆，但總桌數為 76 筆，兩者數量不符，店家想確認原因。

客服初步測試共桌、併桌、拆帳時，交易總筆數與總桌數皆會相符。

但若操作兩筆交易後退貨一筆，交易總筆數會變成 1，總桌數會變成 3。

## 查詢結果

測試 v4.X.X 也有相同問題。

確認問題為操作退貨後，交班帳總桌數會虛增。

透過 資料庫追蹤工具 追查，確認交班帳總桌數相關查詢會將退貨單也計入。

問題點是報表查詢有排除取消單，但退貨單的排除條件未正確套用，導致退貨或退換貨流程產生的資料仍被總桌數統計納入。

公開版不保留內部 SQL、資料表名稱與欄位名稱，只保留查證結論：

```text
交班帳總桌數統計
  已排除：取消單
  未正確排除：退貨 / 退換貨相關單據
  結果：總桌數被退貨流程虛增
```

v4.X.X 測試結果：

- 操作退貨後，總桌數會變成 2。
- 操作退換貨後，總桌數會變成 3。
- 操作退貨後再反銷退，總桌數正確呈現 1。
- 操作退換貨後再反銷退，總桌數正確呈現 1。

## 處理判定

系統問題，已上 Issue [ID]，請開發端 修正交班帳總桌數計算時將退貨單計入的問題。
