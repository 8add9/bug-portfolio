# Case 034 - 跨區域桌況操作後新單不顯示佔桌

## 客服反映內容

測試日期：[DATE]  
POS 版次：v4.0.2  
結帳方式：後結  
線上點餐平台版本：[線上點餐平台]  
相關問題：Redmine #777 同類型

問題：

跨區域操作桌況功能後，再開立新單並掛單，會發生區域與桌號對應錯亂，導致新單未正確顯示佔桌狀態。

受影響操作包含：

- 跨區域併桌 / 併單
- 跨區域移菜
- 跨區域換桌 / 帶位

## 查詢結果

### 情境一：跨區域併桌 / 併單後，新單未呈現佔桌

測試資料：

- 內用桌 orderid：[ID]
- 外帶桌 orderid：[ID]

操作流程：

- [TIME]：點開內用桌。
- [TIME]：掛單。
- [TIME]：使用桌況功能併桌 / 併單，點選外帶的內用桌區域，選擇外帶桌，再於提示視窗點選捨棄變更。
- [TIME]：畫面開始錯亂，區域選中的是內用，但桌況畫面卻呈現外帶的內用桌。
- [TIME]：點開外帶桌時，訂單區域顯示為內用，但桌號卻是外帶區域的桌號。
- [TIME]：點選掛單後，畫面呈現內用區域桌況。
- [TIME]：切換至外帶的內用桌區域時，外帶桌沒有呈現佔桌。

正確行為：

- 外帶桌應位於外帶的內用桌區域。
- 掛單後該桌應呈現佔桌狀態。
