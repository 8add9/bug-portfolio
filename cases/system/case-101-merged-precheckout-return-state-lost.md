# Case 101 - 併單預結帳後重複單據與整單退貨狀態遺失

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

結帳方式：後結

門店查帳發現一筆負 45,700 元資料可在商品銷售明細看到，但交班帳與營業總表的退單金額仍為 0。後續重新處理作廢，才使帳務顯示正確負向金額。

## 查詢結果

排查包含兩個相關異常：

- 併單進入結帳後切換預結帳，再回桌況，主桌出現兩張相同資訊訂單；此情境以模擬畫面呈現。
- 原銷售單操作整單退貨後，雖建立負 45,700 元交易，卻保留一般銷售狀態，未產生正常退貨狀態與付款資料。

操作順序：

1. 主桌與另一桌先併桌，再執行併單去結帳。
2. 開啟預結帳後返回點餐區與桌況，主桌出現重複資訊單據。
3. 點開被併桌，取消預結帳、操作尾數折讓並回桌況。
4. 再次進入訂單，選取商品並完成結帳；主桌兩張單據一併結掉。
5. 在交易紀錄執行銷售退貨、整單退貨。
6. log 實際記錄一般付款與完成結帳，而非退貨流程。

確認退貨標記在結帳前遺失，使負向資料誤走一般付款流程，導致退貨金額未正確呈現於交班帳與營業總表。

## 處理判定

系統問題，已回報 Issue 管理系統。需追蹤併單與預結帳狀態，確保整單退貨走正確流程並一致更新報表。
