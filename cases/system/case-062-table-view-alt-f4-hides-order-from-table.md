# Case 062 - 桌況畫面按 Alt+F4 後新掛單未顯示於桌況

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，在桌況畫面直接按下 `Alt+F4`，桌況介面會消失並進入點餐畫面。此時可以繼續點餐與掛單，但掛單後訂單不會顯示在桌況上，只能到控場區搜尋。

## 查詢結果

測試流程：

- [DATE] [TIME]：在桌況畫面按下 `Alt+F4`。
- 桌況畫面消失，系統直接進入點餐畫面。
- [DATE] [TIME]：加點商品並操作掛單。

實際結果：

- 掛單後桌況畫面沒有該筆訂單。
- 訂單只能從控場區找到。

預期結果：

- `Alt+F4` 不應繞過正常開桌或建立訂單流程。
- 若不允許關閉桌況畫面，系統應攔截快捷鍵。
- 後續建立的訂單應具有正確區域與桌號關聯，並顯示於桌況。

判斷 `Alt+F4` 使桌況視窗異常關閉後，系統仍允許在缺少完整桌位狀態的情況下建立訂單，造成掛單資料無法與桌況正確關聯。

## 處理判定

系統問題，已上 Issue [ID]，請開發端修正桌況視窗的關閉事件，並阻擋在桌位狀態未完整建立時進入點餐與掛單流程。
