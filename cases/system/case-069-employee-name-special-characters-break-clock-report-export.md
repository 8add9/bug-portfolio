# Case 069 - 帳號姓名含特殊符號造成打卡報表無法匯出

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

自主測試發現，帳號姓名包含 Windows 路徑或檔名不允許的特殊符號時，匯出打卡記錄會發生錯誤，無法產生報表。

受影響字元包含：

```text
" < > & * : | / \ ?
```

## 查詢結果

特殊符號或路徑保留字元會造成路徑參數錯誤，錯誤發生於建立 Excel 檔案時：

```text
System.ArgumentException: 路徑中有不合法的字元。
```

帳號姓名包含反斜線時，系統會將姓名的一部分當成子目錄，造成指定路徑不存在：

```text
System.IO.DirectoryNotFoundException: 找不到路徑的一部分。
```

從錯誤堆疊可確認，系統將帳號姓名直接組合進打卡報表的輸出路徑或檔名，未先替換不合法字元。

預期行為：

- 帳號姓名可保留原始內容。
- 產生匯出檔名時，應將不合法字元替換為安全字元。
- 單一帳號姓名不應阻擋整份打卡報表匯出。

## 處理判定

系統問題，已上 Issue [ID]，請開發端在組合匯出路徑前清理或替換帳號姓名中的保留字元，並對檔案寫入錯誤提供可理解的提示。
