# Case 054 - 登入出單機檢查結果視窗按 Alt+F4 後系統無法操作

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

自主測試發現，登入 POS 後系統會顯示出單機狀態檢查結果。若不透過畫面按鈕關閉，而是直接按下 `Alt+F4` 關閉該視窗，POS 後續會進入無法操作的狀態。

發生後只能強制關閉 POS，再重新啟動程式才能恢復操作。

## 查詢結果

可重現流程：

- 登入 POS。
- 等待系統顯示出單機狀態檢查結果視窗。
- 在該視窗按下 `Alt+F4`。
- 檢查結果視窗關閉後，POS 主畫面無法繼續操作。

預期行為：

- 系統應阻擋不允許的關閉方式，或在視窗關閉後正確恢復主畫面的操作狀態。
- 使用者不應需要強制結束並重啟 POS。


## 處理判定

系統問題，已上 Issue [ID]，請開發端修正出單機狀態檢查結果視窗的關閉事件與主畫面狀態恢復邏輯。
