# Case 035 - 出單設定指定區域僅顯示內用區域

## 客服反映內容

測試日期：[DATE]  
POS 版次：v4.X.X  
結帳方式：不分前後結  
模式：桌況模式

問題：

在單據樣板的出單設定中，選擇綁定區域方式為「指定區域」時，區域總攬表只顯示桌況區域設定為「內用」的區域。

操作路徑：

```text
系統設定 > 單據設備管理 > 單據樣板 > 出單設定
```

範例：

桌況區域共有 5 項：

- 內用
- 外帶
- 線上外帶
- 外送
- 線上外送

但在指定區域設定介面中，只呈現「內用」1 項。

## 查詢結果

以下單據類型皆有相同問題：

- 標籤
- 廚房單
- 廚房總單
- 退廚房單
- 退廚房總單
- 催菜單
- 取餐單
- 預結帳單
- 結帳單
- 退貨單

因指定區域清單只顯示內用區域，店家無法針對外帶、外送、線上外帶、線上外送等區域設定不同出單規則。

例如店家想設定「結帳時門店外送要出結帳單、線上外送不出結帳單」，目前無法透過指定區域完成設定。

## 處理判定

系統問題，已上 Issue 管理系統，請開發端 修正單據出單設定指定區域時，區域總攬表只顯示內用區域的問題。
