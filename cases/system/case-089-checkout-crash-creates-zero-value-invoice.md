# Case 089 - 結帳閃退後發票金額為零且稅務資料缺漏

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

結帳方式：前結

門店反映兩筆交易結帳時發生異常，開立出的發票金額都是 0 元；交易紀錄與商品銷售明細分別顯示 55 元、135 元，發票統計明細卻顯示 0 元。

## 查詢結果

兩筆訂單均由線上進單，操作結帳時 POS軟體閃退，隨後發票列印金額為 0。門店已作廢並重新開立。

資料庫中的發票稅務資料有大量欄位為空值；事件紀錄顯示門店更新版本後，曾陸續發生多次閃退。

確認結帳閃退時，發票稅務資料缺漏，造成發票金額為 0，與交易金額不一致。

## 處理判定

系統問題，已回報 Issue 管理系統。需處理結帳中斷時的交易與發票資料一致性。
