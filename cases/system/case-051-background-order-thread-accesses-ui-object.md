# Case 051 - 背景拉單執行緒誤呼叫 UI 物件導致訂單未進 POS

## 客服反映內容

項次：[ID]

門市：[門市/公司]

POS 版次：v4.X.X

結帳方式：前結

線上點餐平台版本：[線上點餐平台]

下單時間：[DATE] [TIME]

銷售單號：[ID]

訂單編號：[ID]

訂單狀態：處理中

客服反映此筆線上訂單沒有進單到 POS，查看控場區也沒有該筆訂單。

## 查詢結果

查看 log，確認訂單拉單流程出現跨執行緒存取錯誤：

```text
呼叫執行緒無法存取此物件，因為此物件屬於另一個執行緒。
```

透過除錯工具 檢查後確認，畫面清除功能 屬於 UI 執行緒物件，但背景拉單執行緒在處理線上訂單時錯誤呼叫 畫面清除功能，因此拋出跨執行緒存取例外。

錯誤發生後，後續訂單流程沒有繼續寫入 POS 資料，造成線上訂單狀態仍存在於線上點餐平台，但 POS 與控場區都查不到該筆訂單。

批次拉單測試也可穩定重現：

- 拉單筆數為 2 筆以上時，第 1 筆可成功寫入 POS。
- 從第 2 筆開始，log 出現跨執行緒存取錯誤，剩餘訂單皆未寫入 POS。
- 不同線上點餐平台版本均有相同結果。

透過執行期除錯確認，批次流程處理完第 1 筆訂單後，背景拉單執行緒在準備處理後續訂單時呼叫畫面清除功能，因該功能屬於 UI 執行緒而拋出例外。因此問題不只影響單一訂單，也會使同批次第 2 筆以後的訂單全部中斷。

資料流判定：

- 線上訂單建立成功。
- POS 背景拉單執行緒取得訂單資料。
- 第 1 筆訂單成功寫入 POS。
- 背景執行緒誤呼叫 UI 執行緒所屬的 畫面清除功能。
- 程式拋出跨執行緒存取例外。
- 批次訂單寫入流程中斷。
- 第 2 筆以後的訂單未出現在 POS 與控場區。

## 處理判定

系統問題，已上 Issue [ID]，請開發端修正背景拉單執行緒存取 UI 物件的問題，並確保單筆訂單失敗時不會中斷同批次後續訂單。
