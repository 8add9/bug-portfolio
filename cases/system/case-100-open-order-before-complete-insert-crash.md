# Case 100 - 跨執行緒寫入失敗後提單空白並閃退

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

線上點餐平台版本：平台版本一

門店反映訂單進單後提單呈現空白，曾跳出無此訂單類提示，畫面反白並閃退。重啟後找不到原單，已由 POS 重新點餐，但商品與線上訂單不同，客服懷疑與線上點餐歷程或前往結帳有關。

## 查詢結果

排查確認門店為前結，沒有後結的前往結帳流程；該單點商品可直接點選，不必先點主餐。

log 時序：

1. POS軟體開始寫入線上訂單，畫面顯示已接單通知。
2. 門店很快點開該單。
3. 訂單寫入發生跨執行緒物件存取錯誤。
4. 提單流程讀取未正常建立的資料，事件紀錄顯示空值例外並閃退。

可能出現的提示為無法取得單據資料，原現場提示未拍到。相關問題與 Case 051、073 的執行緒異常相近。

## 處理判定

系統問題。先安排版更處理執行緒異常，再觀察空白提單與閃退是否仍發生。
