# Case 032 - 吃到飽總點餐數量控管未累計購物車數量

## 客服反映內容

測試日期：[DATE]  
POS 版次：v4.X.X  
結帳方式：後結  
模式：吃到飽

訂單識別值：[ID]  
線上訂單關聯資訊：[已遮蔽]  
線上訂單關聯編號：[ID]

問題：

吃到飽菜單的商品細項設定中，已設定指定商品的總點餐數量控管：

```text
每人點餐總數：最多 3 份
```

同步菜單到線上點餐平台後，消費者仍可透過購物車累加方式送出超過 3 份的數量。

## 查詢結果

測試流程：

- [DATE] [TIME]：點開桌號並列印掃碼點餐單。
- 消費者直接點選 4 份指定商品時，系統會跳出限制提示。

限制提示：

```text
[指定商品]
單次點餐總數最多 3 份
請先送出訂單再繼續點餐哦
```

但消費者先點選 3 份並加入購物車後，消費者點餐畫面上的總數仍呈現：

```text
總數 0/3
```

正確應呈現：

```text
總數 3/3
```

因購物車內已加入數量未被總數控管累計，消費者可以持續再加點 1 份至購物車。

模擬測試最後送出 8 份，訂單可正常進到 POS，POS 顯示數量也是 8 份。

正確行為應為商品點到 3 份後，即依設定值阻擋繼續加入購物車。

## 處理判定

系統問題，已上 Issue 管理系統，請開發端 修正吃到飽總點餐數量控管未累計購物車內已選數量的問題。
