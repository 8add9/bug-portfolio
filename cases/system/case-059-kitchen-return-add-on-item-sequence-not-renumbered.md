# Case 059 - 退廚後加點造成點單區品項序號不連續

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，訂單操作單項退廚或全部退廚後，點單區剩餘商品與後續加點商品的顯示序號不會重新排序，導致序號出現缺號或直接延續已刪除商品的序號。

結帳單上的品項順序正常，問題僅發生於 POS 點單區畫面。

## 查詢結果

測試流程與結果：

1. 開桌並依序點選 3 項商品，點單區顯示序號 1、2、3，再操作掛單。
2. 退廚第 3 項後重新加點相同商品，新商品顯示為第 4 項；正確應重新呈現為第 3 項。
3. 再退廚原第 2 項，剩餘兩項顯示為 1、3；正確應呈現為 1、2。
4. 再次加點後，畫面顯示為 1、3、4；正確應呈現為 1、2、3。
5. 操作全部退廚後重新加點，唯一商品仍從第 4 項開始；正確應從第 1 項開始。


## 處理判定

系統問題，已上 Issue [ID]，請開發端修正退廚與重新加點後的點單區顯示排序；畫面序號可依結帳單的排序結果重新編排。
