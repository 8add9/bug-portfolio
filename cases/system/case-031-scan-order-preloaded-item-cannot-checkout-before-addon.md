# Case 031 - 掃碼點餐單預帶商品未加點無法結帳

## 客服反映內容

測試日期：[DATE]  
POS 版次：v4.0.2  
結帳方式：後結  
線上點餐平台版本：[線上點餐平台]

orderid：[ID]  
ordernumber：[ID]  
OrderReservationNumber：[ID]

問題：

若設定客層預帶商品，開桌列印掃碼點餐單時，客層預帶商品不會帶出服務費。

此時直接操作結帳，系統會跳出提示：

```text
此為線上訂單 未同步線上點餐服務費率，不允許此操作!
```

即使操作掛單，或手動關閉再開啟服務費按鈕，也仍然無法結帳。必須另外再加點後，系統才會進行訂單同步並允許結帳。

## 查詢結果

測試流程：

- [DATE] [TIME]：開內用桌號並列印掃碼點餐單。
- 系統帶入客層預帶商品。
- 此時服務費為 0，正確應為 102。
- 操作掛單並將品項送廚後，服務費仍呈現 0。
- 將服務費按鈕關閉再開啟後，服務費仍呈現 0。
- 此時仍無法結帳，系統持續提示未同步線上點餐服務費率。
- [DATE] [TIME]：另外加點商品後再點選結帳。
- 系統才進行訂單同步，同步完成後可以操作結帳。

判斷開桌列印掃碼點餐單時，客層預帶商品未觸發服務費計算與線上點餐訂單同步。掛單與服務費開關也未重新觸發同步，只有後續新增加點才會觸發同步流程。

## 處理判定

系統問題，已上 Redmine，請 RD 修正掃碼點餐單預帶商品未加點時的服務費計算與訂單同步觸發條件。
