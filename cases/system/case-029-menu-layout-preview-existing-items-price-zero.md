# Case 029 - 修改菜單排版後既有商品預覽價格變 0

## 客服反映內容

店名：[門市/公司]  
POS 版次：v4.0.1  
測試版次：v4.0.2 也有相同問題  
線上點餐平台版本：[線上點餐平台]

問題：

修改菜單到第二步驟「點餐畫面排版」時，若類別內原本已存在其他商品，再拉入新商品後，右側預覽點餐畫面中，原本已存在的商品價格會呈現 0 元。

## 查詢結果

操作路徑：

```text
系統設定 > 菜單管理 > 菜單列表 > 檢視 > 修改菜單 > 2 點餐畫面排版 > 點擊類別
```

重現流程：

- 進入指定類別後，查看右側預覽點餐畫面，原本類別內商品皆有正常售價。
- 點選「修改類別」。
- 點選「加入商品」。
- 選擇新商品後按下確認。
- 再次查看右側預覽點餐畫面。

實際結果：

- 原本類別內已存在的商品價格全部呈現 0 元。
- 只有本次新加入的商品維持正確售價。

預期結果：

- 加入新商品後，原本已存在的商品應維持原售價。
- 新加入商品也應顯示正確售價。

## 處理判定

系統問題，已上 Redmine，請 RD 修正修改菜單排版加入商品後，預覽點餐畫面既有商品價格被重置為 0 的問題。
