# Case 053 - 可退廚數量欄位未阻擋非數字輸入導致閃退

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，單項操作中的可退廚數量欄位沒有阻擋鍵盤輸入。只要在該數字欄位輸入數字以外的字元，POS軟體會直接閃退。

測試流程：

- [DATE] [TIME]：選擇商品並設定數量。
- [DATE] [TIME]：進入單項操作，先執行送廚。
- [DATE] [TIME]：再次進入單項操作，在可退廚數量欄位按下非數字字元。
- POS軟體發生閃退。

## 查詢結果

此問題代表可退廚數量欄位缺少輸入限制或格式驗證，導致非數字字元被帶入後續數量處理流程。

推測後續流程可能直接將欄位內容轉換為數值，當輸入內容不是合法數字時，轉換例外未被攔截，造成 POS軟體閃退。

可重現條件：

- 商品已送廚。
- 單項操作畫面出現可退廚數量欄位。
- 使用鍵盤在數量欄位輸入非數字字元。

## 處理判定

系統問題，已回報開發端。

可退廚數量欄位應限制只能輸入數字，並在後續處理前再次驗證欄位內容。數值轉換失敗時應顯示錯誤提示，不能造成 POS軟體閃退。
