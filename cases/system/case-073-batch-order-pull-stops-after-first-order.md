# Case 073 - 批次拉單僅寫入第一筆訂單

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：平台版本一、平台版本二

一次拉取多筆線上訂單時，只有第一筆成功寫入 POS軟體，第二筆起沒有寫入。

## 查詢結果

測試平台版本一時，一次取得 3 筆訂單，第一筆成功寫入，其餘 2 筆失敗；平台版本二一次取得 2 筆，僅第一筆成功寫入。

log 同時記錄連線成功與跨執行緒存取錯誤：

```text
呼叫執行緒無法存取此物件，因為此物件屬於另一個執行緒。
```

連線成功只表示已取得平台回應，無法代表整批訂單寫入完成。本次測試證實相同例外會影響批次中的後續訂單，與 Case 051 的跨執行緒問題相關。

## 處理判定

系統問題，已回報 Issue 管理系統。批次處理應避免跨執行緒存取，並確認每筆訂單的寫入結果與失敗後處理。
