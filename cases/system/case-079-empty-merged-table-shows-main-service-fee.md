# Case 079 - 併桌後空桌金額誤顯示主桌服務費

## 自主測試內容

POS 版次：v4.X.X

結帳方式：後結

線上點餐平台版本：平台版本一、平台版本二

將空桌選為被併桌，操作併桌回桌況後，空桌顯示主桌服務費金額，且出現未送廚狀態。

## 查詢結果

測試流程：

1. 主桌點餐金額 75 元，服務費 8 元，完成掛單。
2. 操作併桌／併單，選擇空桌並點選併桌回桌況。
3. 空桌的桌況金額顯示 8 元，並呈現未送廚。
4. 點開空桌確認訂單金額為 0，再回桌況後，顯示恢復為 0。

空桌訂單金額為 0，但桌況誤顯示主桌服務費，確認為桌況顯示異常。

## 處理判定

系統問題，已回報 Issue 管理系統。需修正併桌後桌況金額與送廚狀態的更新。
