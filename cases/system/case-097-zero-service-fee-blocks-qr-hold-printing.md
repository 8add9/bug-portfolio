# Case 097 - 服務費零比例造成掃碼訂單掛單同步與列印失敗

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

結帳方式：後結

列印隨機 QR 後先從 POS 點餐，第一次掛單不出單，第二次掛單跳出未同步訂單提示，關閉後仍未出單。重新同步菜單後曾短暫可出單，但仍需掛單兩次，後續再次失敗。

## 查詢結果

測試確認 POS 與線上商品寫入 API 的連線正常，門店識別設定正常。

事件紀錄出現服務費相關錯誤；將線上點餐平台服務費設為 0% 後，可重現此問題，確認為 BUG。

本案與 Case 027 的零服務費問題相關，但客服反映的直接影響是掛單與列印流程。

## 處理判定

系統問題，已確認 0% 服務費設定會造成掛單同步與列印失敗，已回覆排查結果。
