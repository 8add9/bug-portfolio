# Case 023 - 後台商品管理篩選上下架後搜尋跳錯

## 客服反映內容

店名：[門市/公司]  
POS 版次：v4.0.1  
結帳方式：後結  
線上點餐平台版本：[線上點餐平台]  
線上點餐平台帳號/密碼/檢碼：[SECRET]

問題：

後台商品管理在選擇上架或下架狀態後執行搜尋，系統會跳出 Whoops 錯誤頁。

操作路徑：

```text
後台 > 菜單管理 > 商品管理
```

異常情境：

- 選擇「上架」後搜尋，跳出 Whoops。
- 選擇「下架」後搜尋，跳出 Whoops。

正確行為：

- 選擇「上架」後搜尋，應顯示目前上架商品。
- 選擇「下架」後搜尋，應顯示目前下架商品。

## 查詢結果

後台商品管理的上下架狀態篩選與搜尋功能組合使用時發生錯誤，導致系統無法正常回傳商品列表並顯示 Whoops 錯誤頁。

## 處理判定

系統問題，已上 Redmine，請 RD 修正後台商品管理在上下架狀態篩選後執行搜尋時的錯誤。
