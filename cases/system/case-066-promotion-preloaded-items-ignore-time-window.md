# Case 066 - 非促銷時段開桌預帶商品仍套用促銷

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：[線上點餐平台]

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，促銷活動設定指定時段後，在促銷時段以外開桌，系統仍會對開桌預帶商品套用該促銷。

## 查詢結果

促銷設定：

```text
系統設定 > 促銷管理 > 促銷設定 > 開新促銷活動 > 時段類型 > 指定時段
```

測試情境：

- 促銷活動設定於夜間指定時段生效。
- [DATE] [TIME]：在下午非促銷時段點選桌號並開桌。
- 開桌時帶入的預帶商品立即套用該促銷。

預期結果：

- 非指定時段開桌時，預帶商品不應套用促銷。

判斷開桌預帶商品的促銷計算流程未套用指定時段條件，或使用了與一般加點不同的促銷有效性判斷。

## 處理判定

系統問題，已上 Issue [ID]，請開發端修正預帶商品套用促銷時的日期與時段驗證，並確保與一般點餐流程採用相同規則。
