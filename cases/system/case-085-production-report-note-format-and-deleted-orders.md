# Case 085 - 生產管制報表因備註格式變空白且保留已刪訂單

## 自主測試內容

POS 版次：v4.X.X

自主測試發現時段生產管制表有兩種異常：任何一筆訂單備註不含分隔符號就會使整份報表空白；已刪訂單的商品仍列出，數量顯示 0。

## 查詢結果

情境一：備註格式影響整份報表。

1. 只有備註含 `|` 的線上訂單時，報表正常。
2. 新建 POS 訂單，備註留空或輸入一般文字並掛單，整份報表空白。
3. 將該訂單備註改為包含 `|`，報表恢復。
4. 再移除分隔符號、全部退廚並刪單，整份報表仍空白。

情境二：另一筆已刪除訂單的商品仍出現在報表中，數量為 0。

確認報表受到訂單備註格式影響，且已刪訂單仍出現在報表中。

## 處理判定

系統問題，已回報 Issue 管理系統。一般備註不應使整份報表失效，已刪訂單的顯示規則也需一致。
