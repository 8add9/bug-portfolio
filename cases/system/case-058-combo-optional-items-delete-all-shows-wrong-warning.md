# Case 058 - 套餐任選商品送廚後全部刪除顯示錯誤提示

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

訂單識別值：[ID]

線上訂單關聯編號：[ID]

套餐的指定組合設定如下：

- 可選商品個數：不控管。
- 商品狀態：任選。

自主測試發現，選擇該組合內的任選商品並送廚後，再對組合操作全部刪除，系統顯示「全部商品皆為必選，不可以做刪除」；但這些商品並非必選，真正不能刪除的原因是商品已送廚。

## 查詢結果

測試流程：

- [DATE] [TIME]：點選桌號並開桌。
- 點選套餐，在任選組合中選擇多個商品。
- [DATE] [TIME]：操作掛單並送廚。
- [DATE] [TIME]：再次點選套餐組合，操作全部刪除。

實際提示：

```text
全部商品皆為「必選」，不可以做刪除唷!
```

正確提示應為：

```text
已送廚，不允許此操作!
```

判斷全部刪除流程的驗證順序或提示條件錯誤，將已送廚的任選商品誤判為必選商品。

## 處理判定

系統問題，已上 Issue [ID]，請開發端修正套餐組合全部刪除時的狀態判斷與錯誤訊息對應。
