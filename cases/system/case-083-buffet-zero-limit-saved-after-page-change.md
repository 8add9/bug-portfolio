# Case 083 - 吃到飽數量上限切換分頁後可儲存為零

## 自主測試內容

POS 版次：v4.X.X

結帳方式：後結

線上點餐平台版本：平台版本二

吃到飽菜單將每人數量上限設為 0 時，直接下一步會被阻擋，但先切換商品分頁後，即可儲存非法設定。

## 查詢結果

重現步驟：

1. 在吃到飽商品細項設定，將每人單次點餐最多份數設為 0。
2. 直接點下一步，系統提示「必填欄位不可為空白或是小於1唷!」。
3. 切換至其他商品分頁，再點下一步。
4. 可以完成儲存；重新檢視菜單，設定確實為 0。

總點餐數量控管也有相同問題。驗證未涵蓋所有分頁的待儲存資料。

## 處理判定

系統問題，已回報 Issue 管理系統。儲存前應檢核全部商品分頁，而非只驗證目前畫面的欄位。
