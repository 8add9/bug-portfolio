# Case 103 - 背景線上進單期間本機交易明細空白並錯置商品

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

結帳方式：前結

門店現場用 POS 點餐結帳，交易金額 90 元，但交易明細空白，廚房與吧台也沒有出單，需協助排查。

## 查詢結果

查得兩筆相關本機訂單：

- 訂單 B 已結帳 90 元，資料庫找不到對應商品明細。
- 前一筆訂單 A 仍為掛單，卻不在控場，已被標記為抽屜狀態。單頭金額為 45 元，但明細商品數量已改為 2，應為 90 元。

操作時序：

1. 門店開立訂單 A，同時間背景寫入一筆線上訂單。
2. 點選 45 元商品並結帳，畫面提示沒有訂單。
3. 再次開桌成立訂單 B，畫面帶出原本的 45 元商品。
4. 將數量改為 2 並結帳。
5. 訂單 B 無明細，訂單 A 的明細被改為 2 份，但單頭金額未同步。

確認背景線上進單與本機點餐同時發生時，商品明細異動到前一筆訂單，新交易卻沒有商品明細，造成兩筆訂單資料不一致。

## 處理判定

系統問題，已回報 Issue 管理系統。需追查併發操作的訂單隔離及單頭、明細、列印資料一致性。
