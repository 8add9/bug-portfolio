# Case 027 - 線上點餐服務費 0% 被判定未同步

## 客服反映內容

店名：[門市/公司]  
POS 版次：v4.0.1  
測試版次：v4.0.2 也有相同問題  
結帳方式：後結  
線上點餐平台版本：[線上點餐平台]

orderid：[ID]  
OrderReservationNumber：[ID]

問題：

線上點餐後台設定服務費 0%。從 POS 開桌列印掃碼點餐單後，直接從 POS 點餐並結帳，系統會跳出提示：

```text
此為線上訂單 未同步線上點餐服務費率，不允許此操作!
```

## 查詢結果

測試流程：

- [DATE] [TIME]：點選內用桌號開桌並列印掃碼點餐單，直接從 POS 點餐。
- [DATE] [TIME]：點選結帳，系統提示訂單金額有異動，正在與線上點餐訂單同步。
- [DATE] [TIME]：系統提示與線上點餐同步完成，訂單金額已更新。
- [DATE] [TIME]：再次點選結帳，跳出服務費率未同步提示，無法結帳。

服務費設定測試結果：

- 情境 1：POS 設定不收服務費，線上點餐設定收服務費，可以結帳。
- 情境 2：POS 設定不收服務費，線上點餐設定不收服務費，不可以結帳。
- 情境 3：POS 設定收服務費，線上點餐設定收服務費，可以結帳。
- 情境 4：POS 設定收服務費，線上點餐設定不收服務費，不可以結帳。

判斷當線上點餐服務費率為 0% 時，系統將其判定為未同步服務費率，導致後結訂單無法結帳。

## 處理判定

系統問題，已上 Redmine，請 RD 修正服務費率為 0% 時被誤判為未同步的判斷邏輯。
