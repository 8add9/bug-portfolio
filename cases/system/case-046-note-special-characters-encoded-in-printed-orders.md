# Case 046 - 備註特殊符號列印時被編碼

## 自主測試內容

測試日期：[DATE]

POS 版次：v4.0.2

結帳方式：後結

線上點餐平台版本：[線上點餐平台]

orderid：[ID]

OrderReservationNumber：[ID]

OrderNumber：[ID]

於線上點餐平台的商品備註與整單備註輸入特殊符號：單引號、雙引號、小於、大於、`&` 符號。訂單進 POS 後列印廚房單、廚房總單、點餐單、外送單、結帳單時，備註內容會呈現 encode 後的文字。

正確結果應為列印使用者實際輸入的符號，或在輸入端阻擋不支援的特殊符號。

## 查詢結果

查看 luapilog，訂單寫入時備註內容已經被 encode。

單據呈現差異：

- 廚房單：商品備註異常，整單備註正常。
- 廚房總單：商品備註與整單備註均異常。
- 點餐單：商品備註與整單備註均異常。
- 外送單：商品備註與整單備註均異常。
- 結帳單：商品備註與整單備註均異常。

測試流程：

- [DATE] [TIME]：開桌並列印掃碼點餐單。
- [DATE] [TIME]：訂單進 POS，列印廚房單、廚房總單、點餐單。
- [DATE] [TIME]：操作結帳，列印外送單、結帳單。

判斷為訂單備註在寫入、同步或列印流程中有 encode/decode 處理不一致，導致多種單據列印備註異常。
