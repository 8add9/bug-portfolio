# Case 080 - 斷線期間開立再作廢的發票無法補傳

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：平台版本一、平台版本二

網路中斷期間完成結帳並開立發票，在尚未上傳前整單退貨並作廢發票；恢復網路後仍無法上傳。

## 查詢結果

重現順序：

1. 中斷網路。
2. 結帳並開立尚未上傳的發票。
3. 網路恢復前執行整單退貨，確認作廢發票。
4. 恢復網路並執行電子發票交易上傳。
5. 該筆資料持續顯示無法取得發票內容，未完成補傳。

測試確認開立與作廢先後都發生於斷線期間，恢復連線仍未解決；原始發票號碼與外部狀態碼未保留。

## 處理判定

系統問題，已回報 Issue 管理系統。需檢查離線開立與作廢的資料保存及恢復後上傳順序。
