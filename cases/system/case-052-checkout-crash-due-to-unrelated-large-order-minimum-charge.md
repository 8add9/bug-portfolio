# Case 052 - 結帳時誤抓其他桌大額訂單導致閃退

## 客服反映內容

項次：[ID]

門市：[門市/公司]

POS 版次：v4.X.X

結帳方式：後結

線上點餐平台版本：[線上點餐平台]

客服反映原本只有特定桌位點選結帳會閃退，後續變成每一桌都有相同狀況。移菜、開新桌、併桌後也一樣，只要點選結帳就會閃退。

## 查詢結果

查詢後確認，當時其中一桌存在超過 `Int16` 上限的高金額訂單。

任意桌位執行結帳時，POS軟體會查詢個別結帳或多菜單相關資料。該查詢條件除了比對目前訂單外，也會比對一個空白的主個別結帳識別值。

因為該高金額桌位符合空白主個別結帳識別值條件，所以其他桌位執行結帳時，也會一併抓到該高金額桌位資料。

後續流程會將抓到的訂單金額帶入低消比對。低消比對過程中，系統嘗試將總金額轉換為 `Int16`。

`Int16` 可接受範圍為 -32768 至 32767。當被誤抓到的高金額訂單超過此範圍時，轉換失敗並造成 POS軟體閃退。

資料流判定：

- 某桌存在超過 `Int16` 上限的大額訂單。
- 其他任意桌位點選結帳。
- 結帳流程查詢個別結帳或多菜單關聯資料。
- 查詢條件誤抓到不屬於目前結帳桌位的大額訂單。
- 系統將該大額訂單帶入低消比對。
- 金額轉換為 `Int16` 時失敗。
- POS 發生閃退。

## 處理判定

系統問題，已回報開發端。
