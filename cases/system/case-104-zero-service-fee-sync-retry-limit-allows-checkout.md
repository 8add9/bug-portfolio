# Case 104 - 零服務費訂單同步失敗達上限後可結帳

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

結帳方式：後結、固定 QR

門店結帳時反覆出現金額異動同步中及同步未成功提示。曾修改菜單價格，但已同步菜單並重啟；線上後台未收服務費，仍需協助排查。

## 查詢結果

平台版本二不收服務費的套餐訂單，可觀察到前三次結帳或掛單均提示同步失敗，之後才可結帳。

查詢追蹤確認待同步紀錄僅處理重試次數小於 3 的資料。三次失敗後，次數已達 3，但狀態仍為未同步，後續不再被選入同步流程。

同時間 API 連線成功。第四次可以結帳，是因為未同步資料已被重試條件排除，同步狀態仍為失敗。

確認線上平台不收服務費的訂單會反覆同步失敗，達到重試上限後，仍未同步的資料不再被處理。

## 處理判定

系統問題，已回報 Issue 管理系統。需處理零費率同步與重試用盡狀態，不應透過略過未同步資料來完成流程。
