# Case 020 - 跨區域併桌後單據未顯示於桌況

## 客服反映內容

項次：[ID]  
店名：[門市/公司]  
POS 版次：v3.X.X  
結帳方式：後結

客服回報現場桌號 [TABLE] 的單據掛單後沒有出單。

本班營業額有包含該筆掛單金額，後續確認此筆訂單出現在控場區，店家想確認為何該筆單據會在控場區。

## 查詢結果

查詢資料後，確認該筆單據寫入的區域是外帶區域，而不是該桌號所在的內用區域。

該筆單據是由 POS02 操作。

查看 POS02 buttonlog 後，還原情境如下：

- 系統有兩個圖形化桌況區域：內用區與外帶區。
- 店家跨區域操作併桌。
- 跨區域併桌後，桌位顯示到相反的區域。
- 此時再點餐並掛單，會因為資料區域與桌號對不起來，導致桌況無法顯示該筆單據。

測試 v4.X.X 也有相同問題。

## 處理判定

系統問題，已上 Issue [ID]，請開發端 修正跨圖形化桌況區域併桌後的區域與桌號對應邏輯。
