# Case 018 - 刪除單據確認時誤加商品

## 客服反映內容

項次：[ID]  
店名：[門市/公司]  
POS 版次：v3.2.4hotfix03  
結帳方式：前結  
線上點餐平台帳號/密碼/檢碼：[SECRET]

下單時間：[DATE] [TIME]  
銷售單號：[ID]  
訂單編號：[ID]  
外送平台訂單編號：[ID]

客服回報外送平台訂單進到 POS 後，訂單金額原本為 260 元，但列印結帳單時多了一項商品，金額變成 495 元。

## 查詢結果

店家操作 A 訂單時，點開此筆外送單，系統跳出是否要捨棄此單據的確認視窗。

店家點選「是，刪除單據」後，遮罩未正常跳出，導致點擊穿透到確認按鈕下方的商品按鈕。

因此下方商品被一併點入點餐區，造成結帳單多出該商品，總金額從 260 元變成 495 元。

## 處理判定

系統 UI 問題，已上 Redmine #785，請 RD 修正刪除單據確認流程的遮罩與點擊阻擋邏輯。
