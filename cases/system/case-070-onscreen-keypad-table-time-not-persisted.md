# Case 070 - 畫面數字鍵盤調整桌位時間後欄位未更新

## 自主測試內容

POS 版次：v4.X.X

結帳方式：後結

線上點餐平台版本：[線上點餐平台]

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，使用畫面數字鍵盤調整桌位限時後，桌位狀態會暫時依新值更新，但再次開啟調整視窗時，欄位仍顯示前一次以實體鍵盤輸入的值。此時關閉視窗，舊值還會再次覆寫目前桌位限時。

## 查詢結果

測試流程：

- [DATE] [TIME]：點選桌號並開桌、掛單，原桌位限時為 120 分鐘。
- [DATE] [TIME]：使用實體鍵盤將限時改為 50 分鐘並確認。
- 再次開啟調整視窗，欄位正確顯示 50。
- [DATE] [TIME]：使用畫面數字鍵盤將限時改為 20 分鐘並確認，桌位狀態正確變為提醒。
- 再次開啟調整視窗，欄位仍顯示 50，正確應為 20。
- 點選右上角關閉按鈕後，桌位限時被改回 50 分鐘，桌位狀態也從提醒變回使用中。

判斷畫面數字鍵盤只更新了部分畫面或訂單狀態，未同步更新調整視窗所綁定的資料來源；重新開啟或關閉視窗時，舊值又寫回桌位資料。

## 處理判定

系統問題，已上 Issue [ID]，請開發端統一實體鍵盤與畫面數字鍵盤的資料綁定及儲存流程，並避免關閉未修改的視窗時覆寫目前限時。
