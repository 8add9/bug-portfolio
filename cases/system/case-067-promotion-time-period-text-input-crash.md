# Case 067 - 促銷指定時段上下午文字可被修改並造成閃退

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：[線上點餐平台]

自主測試發現，促銷活動指定時段中的「上午／下午」欄位可以被編輯。刪除部分文字或改成其他內容後，POS 會直接閃退。

新增促銷活動與修改既有促銷活動均可重現。

## 查詢結果

操作路徑：

```text
系統設定 > 促銷管理 > 促銷設定 > 促銷活動 > 時段類型 > 指定時段
```

重現方式：

- 點選指定時段的上午／下午欄位。
- 刪除「上午」中的部分字元，或輸入其他非預期文字。
- 系統處理該欄位時發生閃退。

判斷時段欄位應為固定選項，但畫面允許任意文字輸入；後續解析時未驗證輸入是否為合法時段值，也未攔截轉換例外。

## 處理判定

系統問題，已上 Issue [ID]，請開發端將上午／下午限制為不可任意編輯的選項，並在儲存與解析前驗證時段格式，避免非法內容造成閃退。
