# Case 017 - 線上付款成功但 POS 未進單

## 客服反映內容

項次：[ID]  
店名：[門市/公司]  
POS 版次：v2.X.X  
結帳方式：前結  
線上點餐平台帳號/密碼/檢碼：[SECRET]

下單時間：[DATE] [TIME]  
銷售單號：[ID]  
訂單編號：[ID]

客服回報主機今日發現有一筆訂單未進 POS，但 線上付款 已收到款項。

客服已引導店家查看控場，確認控場內沒有此訂單，也沒有任何暫存單，需協助確認原因。

## 查詢結果

log 顯示線上點餐端在取單並寫入 POS 時發生訂單寫入失敗。

錯誤類型為物件參考未設定，導致該筆訂單未成功寫入 POS。

由於此門店使用舊版線上點餐介面，進單失敗後不會補傳，因此形成線上付款已成立，但 POS 端沒有訂單與暫存單的狀況。

## 處理判定

系統版本問題，舊版線上點餐介面不支援失敗補傳，安排版更至支援補傳機制的版本。
