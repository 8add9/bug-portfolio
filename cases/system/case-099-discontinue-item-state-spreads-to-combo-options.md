# Case 099 - 單一品項今日下架連帶影響後續套餐組合

## 客服反映內容

項次：[ID]

門店將湯底或附餐品項操作一日下架後，套餐中該品項以下內容呈現反灰。被下架品項顯示停售，其他品項仍有可點選情況；沒有加值口味的品項可用加減號點餐，但送單前仍被提示已售完需重新點餐。

## 查詢結果

平台版本二後台操作商品今日下架後，可重現下架狀態連帶影響後續內容。

測試套餐的第二組合包含 15 個子項，將第 3 個子項下架後，第 3～15 個子項及下一組合也受到影響。

前端檢查確認，自第一個下架商品起，後續商品也帶入相同的停售樣式狀態，造成反灰範圍外溢。

## 處理判定

系統問題，已透過測試確認。需隔離各品項的停售狀態，並統一畫面、加減數量與送單檢核。
