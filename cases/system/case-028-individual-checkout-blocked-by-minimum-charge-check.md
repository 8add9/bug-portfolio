# Case 028 - 個別結帳被低消檢查阻擋

## 客服反映內容

測試日期：[DATE]  
POS 版次：v4.0.2  
結帳方式：不分前後結  
線上點餐平台版本：[線上點餐平台]

orderid：[ID]  
OrderReservationNumber：[ID]

問題：

此線上點餐版本沒有客層與多菜單模組，但操作個別結帳時，系統會跳出低消檢查提示並阻擋個別結帳。

錯誤提示：

```text
未符合低消不允許個別結帳功能!
```

## 查詢結果

測試流程：

- [DATE] [TIME]：點選內用桌號開桌、點餐並掛單。
- [DATE] [TIME]：操作個別結帳。
- 系統跳出「未符合低消不允許個別結帳功能!」提示，無法繼續個別結帳。

判斷系統在沒有客層與多菜單模組的情境下，仍套用低消相關檢查，導致個別結帳功能被錯誤阻擋。

## 處理判定

系統問題，已上 Redmine，請 RD 修正個別結帳時低消檢查的適用條件。
