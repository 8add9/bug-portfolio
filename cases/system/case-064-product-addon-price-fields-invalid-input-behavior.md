# Case 064 - 商品與加值價格欄位對負號及非數字輸入處理異常

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：[線上點餐平台]

自主測試發現，商品價格與加值加減價欄位存在多種輸入驗證異常，包含負號被移除、運算式輸入導致平台售價歸零，以及非數字內容造成 POS 閃退。

受影響欄位：

- 商品售價。
- 商品最低價。
- 各平台售價。
- 加值價格加減價。

## 查詢結果

### 情境一：負數儲存後變成正數

- 在商品售價或加值價格加減價輸入 -1。
- 儲存後價格呈現 1。
- 正確應依系統允許的價格規則保存 -1；若不允許負數，則應在儲存前明確阻擋，而不是靜默移除負號。

### 情境二：運算式輸入使平台售價變成 0

- 在商品售價輸入類似 `3*50` 的內容。
- 點選將門店售價代入各平台售價。
- 各平台售價變成 0。
- 加值價格加減價欄位也有相同問題。

### 情境三：非數字內容造成閃退

- 在價格欄位輸入連續負號、連續星號，或複製貼上純中文、英文及符號。
- 點選儲存後，POS 發生閃退。
- 商品價格與加值價格加減價欄位均可重現。

判斷相關價格欄位缺少一致的輸入限制、格式驗證與數值轉換例外處理，不同操作流程對相同輸入採用不同的錯誤處理方式。

## 處理判定

系統問題，已上 Issue [ID]，請開發端統一商品與加值價格欄位的合法格式及範圍驗證。非法輸入應顯示提示並阻擋儲存，不可自動改值、帶入 0 或造成 POS 閃退。
