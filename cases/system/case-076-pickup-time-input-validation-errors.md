# Case 076 - 預訂取餐時間欄位可輸入非法內容並造成閃退

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

啟用開桌前輸入顧客資料後，預訂取餐時間欄位可修改上下午文字、輸入過去時間及超過 12 的小時數，分別造成閃退或錯誤時間。

## 查詢結果

三種測試情境：

1. 將「上午」刪除部分文字或改為「中午」，POS軟體立即閃退。
2. 輸入早於目前時間的日期與時間，仍可繼續操作，未提示過去的預訂時間。
3. 在 12 小時制欄位輸入 14 並選擇上午，掛單後單據的預訂取餐時間變成 00:00。

第一種情境與 Case 067 的時段文字輸入問題相近，但發生於顧客資料輸入流程。

## 處理判定

系統問題，已回報 Issue 管理系統。時間欄位需驗證格式與範圍；過去時間是否允許應明確定義並提示。
