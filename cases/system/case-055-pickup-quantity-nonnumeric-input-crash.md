# Case 055 - 領取商品數量輸入非數字造成閃退

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，會員領取商品時，「本次領取數量」欄位可以輸入非數字字元。透過實體鍵盤輸入，或複製貼上非數字內容後按下確認，POS 都會直接閃退。

## 查詢結果

測試流程：

- [DATE] [TIME]：點選桌號並開桌。
- [DATE] [TIME]：選擇領取商品。
- [DATE] [TIME]：點選本次領取數量欄位，輸入非數字字元。
- 點選確認後，POS 發生閃退。

測試結果：

- 使用鍵盤輸入非數字字元可以重現。
- 複製貼上非數字內容也可以重現。

判斷「本次領取數量」欄位缺少輸入限制與送出前的數值驗證。非數字內容進入後續數量處理或型別轉換流程時，例外未被攔截，造成 POS 閃退。

## 處理判定

系統問題，已上 Issue [ID]，請開發端限制領取數量只能輸入合法數字，並在後續處理前再次驗證；格式錯誤時應顯示提示，不可造成 POS 閃退。
