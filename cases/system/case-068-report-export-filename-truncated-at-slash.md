# Case 068 - 報表匯出檔名遇斜線被截斷

## 自主測試內容

POS 版次：v4.X.X

結帳方式：此問題不分前後結

線上點餐平台版本：[線上點餐平台]

自主測試發現，多種報表名稱包含 `/` 時，從報表檢視畫面執行儲存，匯出檔名會從斜線處被截斷，只保留斜線後方的文字。

儲存成不同檔案格式均有相同問題。

## 查詢結果

受影響報表：

- 商品銷售明細表（銷售／退貨）。
- 類別／商品優惠分析表。
- 發票統計／明細表。

實際結果範例：

- 商品銷售明細表匯出後只保留「退貨」以後的檔名。
- 類別／商品優惠分析表匯出後只保留「商品優惠分析表」。
- 發票統計／明細表匯出後只保留「明細表」。

預期結果：

- 匯出檔名應保留完整報表名稱。
- 因 `/` 不適合作為 Windows 檔名字元，系統應在產生檔名時將其安全替換為全形斜線、連字號或其他合法字元，不應直接截斷前半段名稱。

判斷報表名稱轉換為檔名時，系統以 `/` 分割字串或路徑，卻只取最後一段，造成檔名內容遺失。

## 處理判定

系統問題，已上 Issue [ID]，請開發端統一處理報表名稱中的檔案系統保留字元，保留可辨識的完整報表名稱。
