# Case 102 - 提單資料未回填造成操作受阻與切換人員閃退

## 客服反映內容

項次：[ID]

POS 版次：v4.X.X

線上點餐平台版本：平台版本一

客服登錄為後結固定 QR。門店反映點開線上訂單金額為 0，畫面卡住數分鐘後閃退，重啟後正常，已多次發生。

## 查詢結果

排查修正實際結帳方式為前結。

點擊訂單後，畫面清除流程清空目前訂單資料，但後續沒有正確回填，造成不能回桌況與結帳。掛單或刪單仍能繼續操作。

門店持續嘗試回桌況、結帳與工具箱，最後切換服務／點餐人員。該功能未檢查資料是否為空，直接讀取造成閃退。

排查確認期間畫面持續回應操作，回桌況與結帳功能因訂單資料被清空而受阻，最後切換人員時才發生閃退。

## 處理判定

系統問題，已回覆客服說明提單資料未回填及切換人員時的空值異常。
