# Case 047 - 商品備註未正確轉義造成前端腳本執行

## 自主測試內容

POS 版次：v4.X.X

結帳方式：後結

訂單識別值：[ID]

線上訂單關聯編號：[ID]

自主測試發現，於線上點餐商品備註輸入含 HTML 標籤與 JavaScript 事件的特殊內容後，點選送出購物車時，線上點餐頁面會在同一個網站 Origin 下執行該段內容，並跳出測試彈窗。

測試情境：

- 商品 A 備註輸入 script 類型測試內容，加入購物車。
- 商品 B 備註輸入屬性跳脫後接續 script 類型測試內容，加入購物車。
- 商品 C 備註輸入圖片錯誤事件類型測試內容，加入購物車。
- 點選送出購物車後，頁面依序觸發測試彈窗。


## 查詢結果

此問題代表商品備註內容在前端輸出時缺少適當的 HTML 轉義或安全渲染處理，導致使用者輸入可影響頁面 DOM 並執行 JavaScript。

風險：

- 使用者輸入可在同一網站 Origin 下執行 JavaScript。
- 確認並非stored XSS。
  
建議修正方向：

- 商品備註與整單備註輸出到 HTML 前必須依輸出情境做轉義。
- 前端渲染備註時應使用純文字節點或安全模板，不可直接寫入 HTML。
- 後端可對備註欄位加入輸入限制或清洗，但輸出端轉義仍不可省略。
- 對購物車、訂單明細、店家後台、POS 顯示頁面一併檢查相同欄位。
- 加入 XSS regression test，涵蓋標籤、屬性跳脫與事件屬性等輸入情境。

## 處理判定

安全漏洞，已回報開發端。
