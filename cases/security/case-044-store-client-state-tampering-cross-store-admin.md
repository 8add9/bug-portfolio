# Case 044 - 店家後台可透過 Cookie 竄改切換店家權限

## 自主測試內容

自主測試發現店家後台登入後，只要修改 Cookie 中的店家識別值，就可能切換到其他店家的後台操作範圍。

在切換識別值後，可對其他店家的後台設定執行操作，例如商品上下架。

## 查詢結果

此問題代表後端授權判斷信任了前端 Cookie 中的店家識別值，未依登入帳號在伺服器端重新驗證該帳號是否有權操作目標店家。

風險：

- 店家可越權操作其他店家的資料。
- 商品、菜單、營業設定等後台資料可能被未授權修改。
- 若遭濫用，會造成跨店資料完整性與營運風險。

建議修正方向：

- 店家識別值只能作為前端狀態，不可作為授權依據。
- 後端每個後台功能都必須依登入 session 驗證可操作的店家範圍。
- 所有修改操作需檢查登入帳號與目標店家的授權關係。
- 對跨店敏感操作加入 audit log。
- 後台 Cookie 內容不可被客戶端竄改後直接影響資料操作範圍。

## 處理判定

安全漏洞，已回報開發端。需修正店家後台依 Cookie 店家識別值造成跨店越權操作的問題。
