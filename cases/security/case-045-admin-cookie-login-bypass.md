# Case 045 - 總後台可透過 Cookie 繞過登入驗證

## 自主測試內容

自主測試發現總後台在未輸入帳號密碼的情況下，只要於瀏覽器 Cookie 加入特定登入狀態值，即可進入總後台。

進入後可操作高權限管理功能，例如店家停權等管理操作。

## 查詢結果

此問題代表總後台登入驗證可被客戶端 Cookie 狀態繞過，後端未正確驗證使用者是否完成帳號密碼登入與權限授權。

風險：

- 未授權使用者可能直接取得總後台操作權限。
- 可執行高影響管理操作，例如停權店家、修改管理設定。
- 屬於高風險驗證繞過與權限控管缺陷。

建議修正方向：

- 總後台不得依賴客戶端 Cookie 字串判斷登入狀態。
- 後端需驗證伺服器端 session 或簽章 token。
- 高權限操作需重新檢查管理員身份與角色權限。
- 登入狀態 Cookie 應使用不可偽造的簽章與有效期限。
- 管理操作需保留 audit log，包含操作者、時間、來源 IP 與操作內容。
- 建議立即盤點是否已有異常登入或未授權管理操作紀錄。

## 處理判定

高風險安全漏洞，已回報 RD。需立即修正總後台登入驗證可被 Cookie 狀態繞過的問題。
