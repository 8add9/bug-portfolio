# Case 043 - 會員登入憑證可跨裝置重用

## 自主測試內容

自主測試發現會員登入後，Cookie 中的會員識別憑證可被複製到其他裝置使用。

其他裝置只要帶入該憑證，即可取得原會員登入狀態，並可操作會員功能。

受影響操作包含：

- 線上點餐下單
- 新增地址
- 修改地址
- 使用會員優惠券

即使原會員在原裝置操作登出，其他裝置上已被複製的憑證仍可繼續使用。

## 查詢結果

此問題代表會員登入狀態主要依賴前端 Cookie 中的識別值，且後端未能在登出後立即使已發出的憑證失效。

風險：

- 會員帳號可能被未授權裝置延用。
- 登出無法終止其他裝置上的既有登入狀態。
- 若 Cookie 外洩，攻擊者可冒用會員進行地址修改、優惠券使用與下單。

建議修正方向：

- 會員登入應使用伺服器端 session 或可撤銷的 token。
- 登出時應使該 session/token 立即失效。
- Cookie 應設定 `HttpOnly`、`Secure`、`SameSite`。
- 後端每次敏感操作都應驗證 session 是否仍有效。
- 會員識別值不可直接作為授權依據。

## 處理判定

安全漏洞，已回報開發端。需修正會員登入憑證可跨裝置重用與登出後未失效的問題。
