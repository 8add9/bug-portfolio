# Case 090 - 發票開立總額與實收差異來自跨日作廢

## 客服反映內容

項次：[ID]

POS 版次：v3.X.X

結帳方式：前結

門店反映當日開立發票合計 36,846 元，但實收為 34,672 元，發票總額高於實收，需協助釐清。

## 查詢結果

排查差額為 2,174 元，來源是非當日開立、在當日作廢的發票。

```text
34,672 + 2,174 = 36,846
```

依回覆，發票開立合計統計的是當日開立發票，先前開立、當日才作廢的發票不會納入該開立合計的扣減，因此與當日實收採用不同範圍。

## 處理判定

報表統計範圍認知問題，請客服說明開立日期與作廢日期不同時的計算差異。
