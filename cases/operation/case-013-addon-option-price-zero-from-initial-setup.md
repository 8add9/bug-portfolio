# Case 013 - 加值選項金額為 0

## 客服反映內容

項次：[ID]

客服回報今日有一筆交易的加值選項金額變為 0 元，正確金額應為 15 元。

後續店家已重新同步菜單至線上點餐平台，因此目前金額皆已恢復正確。

店家表示先前設定此加值選項時，POS 與線上點餐平台的金額都有確認過，但今日交易時金額卻異常變為 0 元。

異常加值選項：[OPTION]

## 查詢結果

查看資料後，確認此加值選項建立於 [DATE]。

[DATE] 第一次從線上點餐平台進單時，該加值選項就沒有計算金額。

因此此問題並非今日才突然跑掉，而是該加值選項一開始就未正確設定或同步完成。後續重新同步菜單後，金額才恢復正常。

## 處理判定

操作/設定問題，請客服向店家說明此加值選項建立後第一次進單即未計價，需確認加值選項設定與菜單同步狀態。
